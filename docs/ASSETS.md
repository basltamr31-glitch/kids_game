# Asset strategy and licence record

## Summary

**Every asset in this game is generated at runtime from original code.** There
are no mesh files, no textures, no animation clips, no audio files, and no
fonts bundled from a third party.

The complete asset manifest is:

| Asset class | Source | Licence |
|---|---|---|
| 3D models | `src/art/MeshKit.ts`, `src/world/*`, `src/characters/*`, `src/animals/*` | Original, this project |
| Textures | None. Faces are drawn to a `<canvas>` at runtime (`src/characters/Face.ts`); the toon ramp is a 64×1 generated `DataTexture` | Original, this project |
| Animation | Procedural pose functions in `CharacterRig.applyClip` / `AnimalRig.update` | Original, this project |
| Music | Generated by `src/audio/AudioManager.ts` over `src/audio/Synth.ts` | Original, this project |
| Sound effects | Synthesised in `AudioManager.play` / `playAnimal` / `playVoice` | Original, this project |
| Launcher icon | `tools/generate-icons.mjs` | Original, this project |
| UI iconography | Unicode emoji, rendered by the system font | Not embedded — see note |
| UI font | System font stack | Not embedded — see note |

**There are no placeholder assets in this project.** Nothing needs replacing
before release.

## Why generate instead of license

1. **Style coherence.** One palette (`src/art/Palette.ts`) drives the cow, the
   chalet, the fence and the UI. A downloaded asset pack cannot give you that,
   and mixing packs is exactly what makes a game look assembled rather than
   authored.
2. **Install size.** The whole game is ~200 KB gzipped. A comparable farm game
   built from purchased assets is 80–300 MB.
3. **Licence risk is zero.** No attribution to track, no "royalty-free" terms to
   re-read when the business model changes, no pack that gets pulled.
4. **Infinite variation is free.** Every cow can have different markings, every
   chicken its own voice pitch, every tree its own silhouette, because they are
   parameters rather than files.

The cost is real and worth stating: you cannot hand-sculpt a specific hero prop.
If a future release wants one, glTF loading can be added without disturbing
anything — `PartBuilder` output and a loaded mesh are both just geometry.

## Two things to resolve before release

### 1. Emoji in the UI

Icons like 🐄 🥚 🌙 are Unicode codepoints rendered by the device's own emoji
font. Nothing is embedded, so **no licence applies to this project** — the same
as displaying any other text.

The consequence is cosmetic, not legal: the icons look different on different
Android versions, and a very old device may render a missing-glyph box. Before
release, either:

- accept it (icons are always paired with a localized text label, so nothing is
  emoji-only and nothing becomes unreadable), or
- replace `icon` fields in `src/content/*` with inline SVG paths drawn from the
  game palette, which would also make them stylistically ours.

The second is the better long-term answer and is a contained change: the `icon`
field is a string used in three places (`Hud`, `Screens`, the prompt bubble).

### 2. Fonts

`src/ui/ui.css` names a stack — Baloo 2, Quicksand, Nunito — and falls back to
the system rounded font. **None of these are bundled**, so on Android the game
currently renders in Roboto, which is fine but generic.

To ship the intended look, embed one rounded font. Baloo 2 and Quicksand are
both SIL Open Font License 1.1, which permits embedding in a commercial app
provided the licence text ships with it. If you do this:

1. put the `.woff2` in `public/fonts/`
2. add an `@font-face` rule
3. add the OFL text to the Credits screen and to `THIRD-PARTY.md`

Subset to Latin + Latin Extended-A (covers all six launch languages) to keep it
under ~30 KB.

## Third-party code

| Package | Version | Licence | Used for |
|---|---|---|---|
| three | 0.180.x | MIT | WebGL rendering |
| @capacitor/* | 7.x | MIT | Native shell, storage, haptics, lifecycle |
| vite, typescript, vitest | — | MIT / Apache-2.0 | Build and test tooling only, not shipped |

All permissive and compatible with a commercial closed-source release. Their
licence texts must be included in the app's Credits screen before submission —
`src/ui/Screens.ts` has the Credits entry ready; it currently states only that
the art, music and sound are original.
