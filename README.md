# Little Alpine Days

**A cozy offline 3D childhood game set on an Alpine family farm.**

*Spend a beautiful day with your family.*

</div>

---

A peaceful game for children aged roughly 4–8. You are a child growing up on a
small farm in a mountain valley: you feed Bella the cow, collect eggs, help Mum
in the kitchen and Dad with the fence, find a butterfly by the garden, eat
dinner with your family, brush your teeth and go to bed. Then it is tomorrow,
and the weather has changed.

There is no score, no timer, no energy bar, no failure and no way to be told
off. Every day is a small story.

## What is here

A complete, running vertical slice with the full production architecture behind
it: a hand-built Alpine valley, a child you customise, three species of animal
with individual personalities, two parents with their own daily routines, a
day/phase/weather/season system, a generated-days engine that keeps going
indefinitely, six languages, a parent gate, an offline-first entitlement model,
and an Android project configured for release.

```
 61 fps · 148 draw calls · 266K triangles · ~200 KB gzipped · 65 tests passing
 Android debug APK builds clean: 4.0 MB, 227 Gradle tasks
```

Every model, animation, texture, sound and piece of music is **generated in
code**. There is not one asset file in the repository.

## Run it

```bash
npm install
npm run dev
```

Then open <http://localhost:5173>. It is landscape-only — make the window wide.

```bash
npm test            # 65 tests
npm run build       # production bundle
npm run android:aab # Android App Bundle
```

Full instructions, including Android signing and the iOS path, are in
[docs/BUILDING.md](docs/BUILDING.md).

## How to play

| | |
|---|---|
| **Tap the ground** | the child walks there |
| **Tap an animal or a parent** | say hello — always free, always available |
| **Tap the floating bubble** | do the thing it is pointing at |
| **Drag** | turn the camera |
| **Pinch** | zoom |
| **⚙️** | parent area, behind a 3-second hold |

There is no tutorial screen. Walking near something makes a big friendly icon
appear over it; that is the whole lesson.

## Design commitments

These are constraints the code actually enforces, not aspirations.

**Nothing can fail.** An activity's worst outcome is a friendly note. The step
interpreter has a walk timeout so an unreachable destination advances the script
rather than stranding the child. `tests/gameplay.test.ts` plays 30 consecutive
generated days and asserts every one completes.

**Animal care is never gated.** Feeding, watering, milking and egg collection
are free forever. Premium adds *breadth* — more areas, more animals, more
things to do — never basic dignity. A test asserts this.

**The child is never sold to.** Every commercial surface is behind the parent
gate. There are no ads, no analytics, no account, no chat, and no free-text
input anywhere in the game.

**Offline is the normal case.** The entitlement is cached and trusted at launch,
so a child on a plane gets the game their parent paid for. The only network
operation in the entire app is Play Billing.

**Tablets are a first-class target.** The UI scales from *physical* screen size,
not viewport pixels, so a button is the same size under a fingertip on a 5"
phone and an 11" tablet. Layouts change at tablet widths rather than stretching.

## Project layout

```
src/
  core/          frame loop, event bus, quality tiers, RNG, config
  platform/      IPlatform → WebPlatform / CapacitorPlatform
  save/          versioned schema + migration chain
  localization/  six languages, 210 keys each
  audio/         procedural synthesis; no audio files
  content/       ← all game data lives here
  art/           palette, materials, procedural mesh construction
  world/         terrain, sky, mountains, buildings, props
  characters/    child + parents, rigs, faces
  animals/       rigs and personality-driven behaviour
  gameplay/      player, camera, input, activities, days, weather
  ui/            DOM overlay, responsive layout
  monetization/  IStore + Entitlements
tools/           icon generator
tests/           65 tests
docs/            the table above
android/         generated by Capacitor, then configured for release
```

Adding a new animal, chore or day means editing `src/content/` and adding
translation keys. Nothing else.
